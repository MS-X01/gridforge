# Changelog

## 1.0.0
First public release — a merge and complete rewrite of *spreadsheet-builder* and *DataView Pro v4*.
- Virtualised editable grid (200k+ rows), multi-sheet workbooks, undo/redo, autosave to IndexedDB
- Import CSV/TSV/Excel/ODS/JSON (encoding + delimiter detection, Windows-1256), export CSV/XLSX/JSON/JSONL/TSV/Markdown/SQL/HTML/XML
- Duplicate finder/remover, text cleanup (incl. Persian digit & Arabic-letter fixes), fill, split/merge, find & replace (regex)
- Safe formula engine, validation rules, statistics, group-by, join / compare / append
- 7 themes, English + Persian (RTL), command palette, keyboard shortcuts
